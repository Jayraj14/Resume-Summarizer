# Resume-Summarizer
This project is a small and simple Ollama based resume summarizer
Hugging face is used for free use of LLM and Ollama's Phi model is used for small size of the LLM.

Ensure to run the code in a virtual environment and install the following Libraries:
pip install streamlit pdfplumber ollama

Make sure to install Ollama from the official [website]: (https://ollama.com/download)
and pull the model 'ollama pull phi'
All this needs to be executed in the Terminal

After all setup is done, and code is pasted in the IDE,
python -m streamlit run Trying1.py
execute the above in terminal to run the code which will open streamlit.
